Listen, Read, Score! - standalone version (full microphone support)

This folder is a complete static website. Host it anywhere static sites are hosted
and the read-aloud scoring (microphone) will work, unlike the Instinct-hosted link
where the hosting platform blocks the microphone.

Easiest option (no account needed):
1. Go to https://app.netlify.com/drop in Chrome.
2. Drag this whole folder (the folder containing index.html) onto the page.
3. Netlify gives you a public link - share that link with students.
Free tier is more than enough for a classroom.

Other options: Cloudflare Pages, GitHub Pages, Vercel - all free for this size.
